# Five-minute demo

1. Start the backend and frontend using the README commands.
2. Paste the fictional timestamped transcript or load `seed-data/demo-transcript.md`; validate and inspect segments.
3. Load a workflow run to inspect generated candidates, scores, and editable drafts.
4. Submit a valid candidate for review; approve it and add it to the mock queue.
5. Import simulated performance, then load the dashboard, experiment readout, and weekly report.
6. End by pointing out the simulated-data banner, human review gate, model-run history, and limitations.
